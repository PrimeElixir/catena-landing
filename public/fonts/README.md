# Catena typography assets

Official Google Fonts OFL sources, retrieved September 5, 2026. Licenses and SHA-256 source/output identifiers are included. No fonts installed on the operating system.

- `inter-latin-variable.woff2`: Inter normal 400-600; optical size fixed at 18 for body and controls.
- `source-serif-4-latin-variable.woff2`: Source Serif 4 normal 400-600, optical-size axis 8-60.
- `source-serif-4-latin-italic-variable.woff2`: Source Serif 4 italic 400-600, optical-size axis 8-60.

Latin, Western European accents and relevant general punctuation are retained. Use system fallbacks for unsupported glyphs. Each web master is derived from the official variable TTF by limiting weight range and subsetting, not by altering the letter design. Retain both OFL license files when redistributing these fonts. Font source TTFs remain in `source/` for asset regeneration; websites need only the chosen WOFF2s and licenses. `font-display: swap` recommended. Brand typography stays at weights 400/500; 600 is available for future functional needs.
