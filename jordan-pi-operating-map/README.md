# Jordan PI Operating Map

This directory contains a responsive, static web version of
`Jordan_PI_Operating_Map_v1.pdf`.

The page preserves the source document's working-interpretation status and its
three-part operating story while adapting the layout for phone, tablet, and
desktop reading. It does not execute actions, connect to production data, or
make claims beyond the source material.

Serve the directory locally from the repository root:

```powershell
python -m http.server 8000 --directory apps/jordan-pi-operating-map
```

Then open `http://localhost:8000`.
